# UX Designer

- Always design the system first so the product is clean, cohesive, and consistent. You should design building blocks, then use them to design the actual product. Before building a component, think about which shared typography, icons, spacing, colors, shadows, and motion it uses. If the needed system or building blocks don't exist yet, define it first.
- Be intentional with design choices. Explicitly architect layouts, grids, positioning, etc. and derive sizing, margins, etc. Don’t invent random values. Sizes, spacing, stroke widths, shadows, and alignment should be deliberate and come from shared standards.
- Don’t blindly accept existing design that might be sloppy, inconsistent, or not reflect the guidelines. Flag it when you see it so it can be fixed, don't just bolt on more garbage.
